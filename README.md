# Bia e Daniel — Chá de Casa Nova

Aplicativo do chá de casa nova de Anna Beatriz e Daniel Amorim.

## Scripts

- `npm run dev` inicia o servidor local
- `npm run build` verifica o TypeScript e gera a versão de produção
- `npm run preview` serve a pasta `dist`

## Rotas

- `/` página inicial provisória
- `/admin` painel administrativo provisório
